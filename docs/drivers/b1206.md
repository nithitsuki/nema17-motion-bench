# B1206 module

## Summary

The B1206 is a standalone two-phase bipolar driver. It has a metal case, a
DIN rail clip, and screw terminals. It uses opto-isolated inputs and DIP
switches. It has no UART.

| Item | Value |
|---|---|
| Peak output current | 6.0 A |
| Current range | 1.9 A to 6.0 A |
| Motor supply | 20 V to 120 V DC (vendor listings) |
| Logic side | Opto-isolated inputs, 5 V typical |
| Microsteps | 1 and 1/2 step only |
| DIP switches | 8 |
| Interface | STEP/DIR or CW/CCW, selected by SW2 |
| UART | None |

## Differences from the other drivers

| Item | B1206 | TB6600 | TMC2209 |
|---|---|---|---|
| Motor supply | 20 V to 120 V | 9 V to 42 V | 4.75 V to 28 V |
| Current | 1.9 A to 6.0 A | 0.5 A to 3.5 A | 1.4 A RMS |
| Current setting | SW6 to SW8 | SW4 to SW6 | UART or VREF |
| Microsteps | 1, 1/2 | 1 to 1/32 | 1 to 1/256 |
| Pulse mode | SW2: single or two pulse | STEP/DIR only | STEP/DIR |
| UART | No | No | Yes |
| Feedback | Error LED | None | DIAG, INDEX, DRV_STATUS |

The B1206 has the highest voltage and current range. It also has the
coarsest microstep setting.

## Wiring

The signal block has six terminals. The negative terminal comes first in each
pair.

| Terminal | Function |
|---|---|
| Pul+ | Step pulse, positive side |
| Pul− | Step pulse, negative side |
| Dir+ | Direction, positive side |
| Dir− | Direction, negative side |
| Ena+ | Enable, positive side |
| Ena− | Enable, negative side |

Each input is an opto-coupler input.

### Common anode

1. Connect Pul+, Dir+, and Ena+ to +5 V.
2. Connect Pul−, Dir−, and Ena− to the controller outputs.
3. The controller pulls an output low to send a signal.
4. Check the opto input current. Keep it below the MCU pin sink limit,
   usually 20 mA.

This mode suits the 3.3 V GPIO on the WeAct board. The 5 V supply must share
a ground with the MCU.

### Common cathode

1. Connect Pul−, Dir−, and Ena− to GND.
2. Connect Pul+, Dir+, and Ena+ to the controller outputs.
3. The controller drives an output high to send a signal.

A 3.3 V output may not turn on the opto-coupler. Check the input current in
the module.

## DIP settings for STEP/DIR

| Switch | Setting | Reason |
|---|---|---|
| SW1 | Leave at the factory setting | Function not documented |
| SW2 | OFF | Single pulse mode, STEP and DIR inputs |
| SW3 | OFF for full step, ON for 1/2 step | 1 step = 200 steps/rev at 1.8° |
| SW4 | Leave at the factory setting | Function not documented |
| SW5 | Leave at the factory setting | Function not documented |
| SW6 | OFF | 1.9 A, the lowest current |
| SW7 | OFF | 1.9 A, the lowest current |
| SW8 | OFF | 1.9 A, the lowest current |

The firmware must use the same steps/rev value as SW3. For a 1.8° motor:

- SW3 OFF: 200 steps/rev.
- SW3 ON: 400 steps/rev.

## Compatibility with the JK42HS48-1684-03F

The lowest current setting is 1.9 A. The motor is rated 1.68 A. The B1206
cannot set a current below the motor rating.

Do not use this driver with the JK42HS48-1684-03F for long runs. Use a larger
motor, such as a NEMA 23 or NEMA 34. If you must test the small motor, keep
the run short and check the motor case temperature.

The 24 V supply is inside the B1206 input range. It is at the low end of the
range.

## CoreXY

The B1206 has full-step and half-step only. It cannot produce the smooth
motion that a CoreXY machine needs. Use the TMC2209 for the CoreXY motors.
Use the B1206 for a large, slow axis or for a test stand.

## Safety

- Connect the motor before you apply motor power.
- Set the DIP switches before you apply power.
- Do not hot-plug the motor. An open coil can damage the driver.
- Disconnect the supply before you change a wire.
- Do not exceed 120 V on the motor supply.
- Mount the module on a metal surface. The case is the heatsink.
- Stop the test if the motor stalls, vibrates, or makes a loud noise.
- Check the supply range on your unit. The vendor pages disagree.
