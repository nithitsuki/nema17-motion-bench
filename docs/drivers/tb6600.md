# TB6600 module

## Summary

The TB6600 is a standalone stepper driver module. It uses the Toshiba
TB6600HG chip. The common module has a metal case and a screw terminal block.

| Item | Value |
|---|---|
| Peak output current | 4.0 A |
| Motor supply | 9 V to 42 V |
| Logic supply | 5 V on the signal side |
| DIP switches | 6: SW1 to SW6 |
| Inputs | Opto-isolated: PUL, DIR, ENA |
| Microsteps | 1, 2/A, 2/B, 4, 8, 16, 32 |
| Interface | STEP/DIR only |
| UART | None |

The module sets the current and the microstep count with the DIP switches.
The firmware cannot change these values.

## Differences from the TMC2209

| Item | TB6600 module | TMC2209 module |
|---|---|---|
| Logic level | 5 V | 3.3 V |
| Current setting | DIP switch | UART register or VREF |
| Microstep setting | DIP switch | UART register or MS1/MS2 |
| StealthChop | No | Yes |
| UART | No | Yes, single wire |
| Current range | 0.5 A to 4.0 A peak | 1.4 A RMS continuous |
| Feedback | None | DIAG, INDEX, DRV_STATUS |

The TB6600 has no register map. Read the DIP switches and put the same values
in the firmware config. The firmware must know the microstep count to compute
the speed.

## Wiring

The signal block has six terminals:

| Terminal | Function |
|---|---|
| PUL+ | Step pulse, positive side |
| PUL− | Step pulse, negative side |
| DIR+ | Direction, positive side |
| DIR− | Direction, negative side |
| ENA+ | Enable, positive side |
| ENA− | Enable, negative side |

Each input is an opto-coupler input. You can wire it in two ways.

### Common anode

1. Connect PUL+, DIR+, and ENA+ to +5 V.
2. Connect PUL−, DIR−, and ENA− to the controller outputs.
3. The controller pulls an output low to send a signal.

This mode suits a 3.3 V MCU. The MCU sinks current and does not drive 5 V
into the opto input. The 5 V supply must share a ground with the MCU. Check
the opto input current. Keep it below the MCU pin sink limit, usually 20 mA.

### Common cathode

1. Connect PUL−, DIR−, and ENA− to GND.
2. Connect PUL+, DIR+, and ENA+ to the controller outputs.
3. The controller drives an output high to send a signal.

This mode needs a 5 V output. A 3.3 V output may not turn on the opto-coupler.
Check the input current in the module manual.

The module needs 5 V on the signal side in both modes. The WeAct STM32G474CEU6
board has a 5 V pin on header P3. Use that pin for the common-anode supply.

The ENA input has the same opto circuit. Check the module label. Some modules
enable the outputs when current flows through ENA. Others disable the outputs.
Measure the motor shaft before you rely on the ENA polarity.

## DIP microsteps

The Handson manual gives this table. SW1, SW2, and SW3 set the microstep count.

| Microsteps | Pulse/rev (manual) | SW1 | SW2 | SW3 |
|---|---:|---|---|---|
| Undefined | Undefined | ON | ON | ON |
| 1 | 20 | ON | ON | OFF |
| 2/A | 400 | ON | OFF | ON |
| 2/B | 400 | OFF | ON | ON |
| 4 | 800 | ON | OFF | OFF |
| 8 | 1600 | OFF | ON | OFF |
| 16 | 3200 | OFF | OFF | ON |
| 32 | 6400 | OFF | OFF | OFF |

The ON/ON/ON row has no function in the manual. Do not use it.

The manual gives 20 pulse/rev for the 1/1 row. A 1.8° motor has 200 full
steps/rev. Use 200 for a 1.8° motor. Use 400 for a 0.9° motor. The other rows
follow the same rule: pulse/rev = full steps/rev × microstep count.

## DIP current

SW4, SW5, and SW6 set the current. The manual gives an RMS value and a peak
value.

| Current RMS (A) | Peak (A) | SW4 | SW5 | SW6 |
|---:|---:|---|---|---|
| 0.5 | 0.7 | ON | ON | ON |
| 1.0 | 1.2 | ON | OFF | ON |
| 1.5 | 1.7 | ON | ON | OFF |
| 2.0 | 2.2 | ON | OFF | OFF |
| 2.5 | 2.7 | OFF | ON | ON |
| 2.8 | 2.9 | OFF | OFF | ON |
| 3.0 | 3.2 | OFF | ON | OFF |
| 3.5 | 4.0 | OFF | OFF | OFF |

Set the switches before you enable the driver. Check the switch positions
against the table before you apply motor power.

## Setting for the JK42HS48-1684-03F

The motor is rated 1.68 A per phase. Use the 1.5 A setting: SW4 ON, SW5 ON,
SW6 OFF. The 1.5 A RMS value stays below the motor rating.

Do not use the 2.0 A setting. The motor is rated below that value. A motor
case above 80 °C is a warning sign. Reduce the current if the case is too hot.

## Safety

- Connect the motor before you apply motor power.
- Set the DIP switches before you apply power.
- Do not hot-plug the motor. An open coil can damage the driver.
- Disconnect the 24 V supply before you change a wire.
- Connect the signal ground to the motor supply ground.
- Do not exceed 42 V on the motor supply.
- Fit the module on a metal surface. The case is the heatsink.
- Stop the test if the motor stalls or makes a loud noise.
