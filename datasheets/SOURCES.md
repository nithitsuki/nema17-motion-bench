## Notes on individual files

### Leison 17HS

The publisher is Ningbo Leison Motor. The copy used here is a mirror at
lk-tronics.com. The original site is nbleisonmotor.com.

### MotionKing 17HS

The catalogue page covers the 17HS series. It is a different document
from the Leison sheet and it has a few extra models (17HS3430,
17HS3616, 17HS4630).

### Handson 17HS4401S

The original host, handsontec.com, did not respond from this network. The
copy used here is a mirror at ja-bots.com. The document is the Handson
"Data Specs" sheet and has 3 pages.

### StepperOnline

The oyostepper.com host serves the same OMC/StepperOnline documents. The
StepperOnline download host returned HTTP 403 for scripted requests.

### Trinamic QSH4218

The copy is from the Farnell datasheet mirror. The manual is revision
V1.06, dated 2011-04-12. Analog Devices now owns Trinamic.

### Trinamic TMC2209 set

The official sources are on analog.com. That host rejected scripted
downloads from this network (HTTP/2 stream reset, then timeouts, and
Mouser returned an HTML bot-check page). The files here come from
distributor mirrors:

- Rev 1.09, the current IC datasheet, dated 2023-02-16. Three
  independent mirrors served byte-identical files, so the copy is
  intact. The other mirrors were
  `cdn-learn.adafruit.com/assets/.../TMC2209_datasheet_rev1.09.pdf` and
  the GitHub repo `mumanchu/mumanchu`.
- Rev 1.05, dated 2020-05-18. Kept because it is the revision quoted by
  several older board vendors.
- SilentStepStick manual V1.20 for hardware revision V2.0. This is the
  Pololu-compatible 2x8 header module. The manual is one A4 sheet with
  the schematic, the BOM, and the microstep pin table.
- BOB manual V1.00. This is the 1.0 x 1.0 inch 2x10 header board.
- EVAL user manual V1.0. The newer V1.2 revision is on analog.com only.

Pinout summary for the SilentStepStick module: GND, VIO, M1B, M1A,
M2A, M2B, GND, VM on one side; DIR, STEP, PDN_UART, UART, SPRD, MS2,
MS1, EN on the other side; INDEX and DIAG on the pin row ends.

### LDO

The series sheet comes from ldomotors.com. The 2504AC drawing comes from
a distributor mirror at onetwo3d.co.uk. The drawing is revision A, dated
2022-10-21.

### MOONS'

The 8-page file is an extract of the MOONS' hybrid stepper catalogue.
Pages 33 to 40 hold the MS17HA (0.9°) and MS17HD (1.8°) sections. The
full catalogue has 70 pages.

### Lin Engineering 4209

The file is the 4209 series catalogue section. It has 2 pages.

### Adafruit 324

Adafruit publishes the datasheet as a JPG, not a PDF. The JPG was
converted to a one-page PDF with ImageMagick. The pixel content is
unchanged. The JPG is 2480 × 3201 pixels.

### NEMA ICS 16

The 2-page file is an extract of NEMA ICS 16-2001. Page 59 holds section
4.1.2.3 and Figure 19. Page 60 holds Table 4 for inch dimension motors.
The full standard has 187 pages. NEMA holds the copyright. The excerpt is
for reference only.
